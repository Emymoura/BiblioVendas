> [!IMPORTANT]
> Este repositório contém o código-fonte e a documentação do **Bibliovendas**, um sistema web completo para gerenciar e disponibilizar livros físicos e digitais (para compra ou aluguel)[cite: 3].

## 📚 Sobre o Projeto
O **Bibliovendas** centraliza as principais operações de comércio e gestão de uma biblioteca digital e física, facilitando a organização, o catálogo, o acompanhamento de pedidos e a exposição de títulos para um público amplo[cite: 3]. O projeto faz parte da disciplina de Programação Orientada a Objetos 2 da UTFPR[cite: 3].

## 🛠️ Tecnologias Utilizadas
O sistema foi desenvolvido com a seguinte stack tecnológica[cite: 3]:
* **Back-end:** Java[cite: 3] (regras de negócio e API)
* **Front-end:** React[cite: 3] (interface web dinâmica e componentes reutilizáveis)
* **Banco de Dados:** MySQL[cite: 3]
* **Ferramentas:** Visual Studio Code, Draw.io (Diagramas) e Git/GitHub[cite: 3]

## 📊 Principais Requisitos do Sistema
* **Perfis de Usuário:** O sistema contempla perfis de *Cliente* e *Prestador de Serviço*[cite: 3].
* **Operações de Livros:** Cadastro, remoção/desativação de livros[cite: 9, 10], e visualização de sinopse, gênero, autor, editora, preço e disponibilidade[cite: 9].
* **Modelos de Negócio:** Suporte a vendas de livros físicos/digitais e **aluguel de livros digitais** com controle de período de acesso[cite: 3, 9, 10].
* **Pagamento e Experiência:** Opções de pagamento por cartão, PIX e boleto[cite: 9], cadastro de cartões[cite: 9], histórico de compras/aluguéis[cite: 9] e sistema de avaliação de experiência dos usuários[cite: 9].
