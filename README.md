> Este repositório contém o código-fonte e a documentação oficial do **Bibliovendas**, um sistema web desenvolvido como projeto da disciplina de Programação Orientada a Objetos 2 (UTFPR).

## 📚 Sobre o Projeto
O **Bibliovendas** é um sistema de site de biblioteca que centraliza as principais operações de disponibilizar livros físicos e digitais para compra e aluguel a um público amplo. O projeto visa facilitar a organização interna, o acompanhamento de pedidos e a exposição comercial do acervo.

## 🛠️ Tecnologias Utilizadas

## 📊 Principais Objetivos e Requisitos
* **Perfis de Usuário:** Suporte a perfis de *Cliente* e *Prestador de Serviço*.
* **Gestão de Livros:** Cadastro, visualização de sinopse/detalhes e desativação/remoção de títulos do catálogo.
* **Modelos de Negócio:** Venda de livros físicos e digitais, além de aluguel de livros digitais com controle de período de acesso.
* **Experiência e Pagamento:** Opções de pagamento via cartão, PIX e boleto, cadastro de cartões, histórico de compras/aluguéis e avaliação de experiência dos usuários.
