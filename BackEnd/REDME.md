## 🚀 Tecnologias e Arquitetura
* **Linguagem:** Java
* **Framework:** Spring Boot
* **Arquitetura:** Padrão em camadas (Controller, Service, Repository, DTO/Entity)
* **Banco de Dados:** MySQL

## 📋 Atividades Principais (Back-End)
* Modelagem das classes de domínio e mapeamento ORM (JPA).
* Desenvolvimento das regras de negócio para compras e **aluguel de livros digitais**.
* Implementação dos endpoints REST para gerenciamento de catálogo, clientes e pedidos.
